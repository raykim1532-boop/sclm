# SCLM 사용자 가이드

> 업무 일정·할 일 통합 관리 시스템 — 처음 쓰는 사람을 위한 안내서
> 접속 주소: **https://sclm.pages.dev**

---

## 0. 시작하기 전에 (중요)

SCLM은 **1인용 시스템**입니다. 비밀번호가 하나이고 데이터도 하나라서, 주소와 비밀번호를 공유하면 **같은 데이터를 함께 보고 고치게 됩니다**.

- 관리자(김성철)와 같은 업무 데이터를 봐야 하는 경우 → 비밀번호를 전달받아 그대로 사용하세요.
- **자기만의 SCLM**을 갖고 싶은 경우 → 마지막 장 "나만의 SCLM 만들기"를 참고하세요.

---

## 1. 접속과 로그인

1. 브라우저에서 **https://sclm.pages.dev** 접속 (크롬 권장)
2. 비밀번호 입력 → 로그인 (이후 같은 브라우저에서는 자동 로그인)
3. 화면이 예전 것처럼 보이면 **Ctrl+Shift+R** (강력 새로고침)

### 휴대폰에 앱처럼 설치 (권장)

| | 방법 |
|---|---|
| **안드로이드 (크롬)** | 접속 → 메뉴(⋮) → **홈 화면에 추가** |
| **아이폰 (사파리)** | 접속 → 공유(□↑) → **홈 화면에 추가** ※ 아이폰은 설치해야 알림을 받을 수 있어요 |

설치하면 아이콘으로 바로 열리고, 인터넷이 끊겨도 마지막 데이터를 볼 수 있습니다.

## 2. 핵심 개념 — "이 앱이 원천이다"

```
SCLM 앱 (입력·수정·확인·알림·캘린더)   ← 여기서 모든 업무를 관리합니다
```

**업무 추가·수정·완료 처리는 전부 앱의 To-do List에서** 합니다. 앱에 넣은 내용이 그대로 유지됩니다.

예전에는 구글 시트가 원천이고 앱이 시트를 읽어오는 구조였습니다. 그래서 **앱에서 바꾼 내용이 다음 동기화 때 시트 값으로 되돌아갔습니다.** 실제로 이런 일이 있었습니다.

- **완료로 바꾼 업무가 진행중으로 되돌아감**

앱에만 있는 기능(첨부파일·산출물 링크·반복 업무·캘린더 연동·AI 비서 등록)은 애초에 시트에 담을 수 없어서, 시트가 원천인 한 계속 덮어써질 수밖에 없었습니다. 그래서 **동기화를 종료하고 앱을 원천으로 바꿨습니다.**

- 기존 업무 **46건은 그대로 유지**됩니다

- **구글 캘린더 연동은 그대로** 동작합니다 (시트와 무관)
- 앞으로 시트에 적은 내용은 **앱에 반영되지 않습니다** — 반드시 앱에 입력하세요

> 되돌리고 싶으면 관리자에게 요청하세요. 코드는 남아 있고 플래그만 꺼둔 상태라 복구할 수 있습니다.

## 3. 화면별 사용법

### 🏠 Dashboard
화면이 두 구역으로 나뉩니다.

- **지금 할 일** — 지연·오늘·이번 주·점검 필요·미완료 전체 타일과, 지연된 업무 / 오늘 / 이번 주 / 점검 필요 카드. 항목을 클릭하면 그 업무가 열립니다.
- **업무 현황** — 아래 분석 카드들.

| 카드 | 내용 |
|---|---|
| **⚠ 데이터 점검** | 지표를 틀어지게 하는 입력 누락이 있을 때만 표시. 항목을 누르면 해당 업무 목록이 나옵니다 |
| **처리 지표** | 평균 완료 소요일(등록→완료) · 기한 준수율 · 이번 달 완료(전월 대비) · 지연 중 건수와 평균 경과일 |
| 진행 상태 분포 | 대기·진행중·완료 비율 |
| **분류 Top** | `대분류 / 중분류 / 소분류` 탭으로 전환. 세 축 모두 같은 눈금입니다 |
| **최근 추이** | 월별 등록 vs 완료 막대 + **미완료 잔량선**. 6개월/12개월 전환 가능 |

**분류 Top 읽는 법** — 한 줄에 "얼마나 큰 덩어리인지"와 "얼마나 처리했는지"가 같이 들어 있습니다.

- **막대 전체 길이** = 그 분류의 전체 건수 (가장 많은 분류가 100%)
- **진한 부분** = 그중 완료된 비율
- 오른쪽 숫자 = `남은 건수 / 전체 · 완료율`
- 정렬은 **남은 일이 많은 순**. 다 끝난 분류는 아래로 내려갑니다
- 분류를 안 넣은 건들은 맨 아래 **(미지정)** 한 줄로 모입니다 — 이게 크면 분류를 채워야 한다는 신호예요
- 고른 탭은 이 기기에 기억됩니다

**추이 카드 읽는 법** — "일이 밀리고 있는지"를 보는 카드입니다.

- 회색 막대 = 그 달에 **등록**된 건수, 초록 막대 = 그 달에 **완료**된 건수
- 막대 아래 숫자(`+2`, `-1`) = 순증감. **빨강(+)이면 처리보다 유입이 많다**는 뜻입니다
- 주황 선과 `잔량 N` = **그 달 말 기준 아직 안 끝난 건수**. 선이 계속 올라가면 밀리는 중이에요
- 막대에 마우스를 올리면 그 달 수치가 한 번에 보입니다
- ⚠️ 주황 선은 막대와 **척도가 다릅니다**(잔량은 누적이라 훨씬 큼). 높이 비교가 아니라 **기울기**로 보세요

> 계산 기준: 소요일은 등록일·완료일이 모두 있는 건만, 기한 준수율은 마감일이 있는 완료 건만 씁니다. 값이 `–`면 계산할 데이터가 아직 없다는 뜻입니다.

**⚠ 데이터 점검 카드가 뜬다면** — 지표가 이상해 보이는 원인이 대부분 여기 있습니다.

| 항목 | 무슨 일이 생기나 | 고치는 법 |
|---|---|---|
| 완료인데 **완료일 없음** | 잔량에 계속 남고, 소요일·준수율 계산에서 빠짐 | 해당 업무를 열어 **완료일** 채우기 |
| 완료일이 **등록일보다 빠름** | 소요일 계산에서 제외 | 둘 중 잘못된 날짜 수정 |
| 완료일은 있는데 **미완료 상태** | 완료인지 아닌지 판단 불가 | 진행상태를 완료로 바꾸거나 완료일 비우기 |
| 미완료인데 **마감일 없음** | 지연 집계·아침 알림에서 빠짐 | 해당 업무를 열어 **마감일** 채우기 |

> 목록 화면의 **📋 복사** 로 대상 목록을 통째로 복사할 수 있습니다. 고친 내용은 앱에 그대로 남습니다(2026-07-28 시트 연동 종료).

### 📆 Calendar
- 업무 마감일과 일정이 월/주 단위로 표시됩니다.
- 빈 날짜 클릭 → 새 일정 등록. 드래그로 날짜 이동.
- 구글 캘린더와 **양방향 동기화**됩니다("SCLM"이라는 전용 캘린더만 사용 — 개인 일정은 건드리지 않음).
- ⚠️ 구글 캘린더에서 SCLM 항목을 지우면 다음 동기화 때 앱에서도 지워집니다.

#### 개인 캘린더 일정도 함께 보기 (읽기 전용)

구글 캘린더의 **다른 캘린더**(기본 캘린더 등)에 넣은 일정은 원래 앱에 안 들어옵니다. 함께 보고 싶다면:

1. 설정 → 구글 캘린더 연동 → **📥 다른 캘린더 가져오기**
2. 가져올 캘린더를 체크하고 **[선택 저장]** (최대 8개) → 바로 동기화됩니다

- 가져온 일정은 캘린더에 **회색**으로 표시되고, **보기만** 됩니다(앱에서 수정·삭제 불가).
- 내용을 바꾸려면 구글 캘린더에서 고치세요 — 다음 동기화 때 반영됩니다.
- 앱은 그 캘린더에 **아무것도 쓰지 않습니다.** 개인 일정이 앱 때문에 바뀌거나 지워질 일은 없어요.
- 체크를 풀면 다음 동기화 때 화면에서 사라집니다(구글 쪽 원본은 그대로).

### ✅ To-do List
- 표 형태로 한눈에. **대분류 > 중분류 > 소분류** 3단 필터와 상태·기간 필터, 정렬을 지원합니다. **업무 추가·수정은 여기서** 합니다.
- 위 단계를 고르면 아래 단계 후보가 그에 맞게 좁혀집니다(대분류를 바꾸면 아래 두 칸은 '전체'로 돌아갑니다).
- 행 클릭 → 상세 편집. **📎 클립 아이콘**으로 견적서·계약서 등 파일 첨부(최대 25MB).
- **분류 일괄 지정**: 체크박스로 여러 건을 고르면 위에 도구 막대가 뜹니다. 거기서 **중분류·소분류를 한꺼번에** 바꿀 수 있어요.
  - 예) 중분류 필터를 `SEMP`로 걸기 → 맨 위 체크박스로 전체 선택 → **소분류 일괄 지정 → 사방넷**
  - `(비우기)`를 고르면 선택한 건들의 값이 비워집니다.
- 상단 버튼으로 리포트를 뽑을 수 있습니다. 둘 다 **📋 복사**(카톡·메일 붙여넣기용) / **⬇ 텍스트로 저장** 지원.
  - **📋 주간리포트** — 이번 주 완료 · 다음 주 마감 예정 · 지연
  - **📅 월간리포트** — 이번 달 완료 · 이번 달 마감인데 미완료 · 다음 달 예정 + 처리 지표와 대분류별 요약

### 📁 Projects (칸반)
대분류(정산·영업·SCM 등)별 보드에서 카드를 끌어 상태를 바꿉니다.

### 🏷️ Categories (분류 체계)

할 일 분류는 **대분류 > 중분류 > 소분류** 3단계입니다.

| 단계 | 예시 | 어디서 관리하나 |
|---|---|---|
| 대분류 | 정산 · 영업 · CS (업무 성격) | **Categories** 1열 — Projects 화면과 같은 것 |
| 중분류 | 마리오아울렛 · 대구백화점 (거래처) | **Categories** 2열 |
| 소분류 | 하프 · 패플 (브랜드 등) | **Categories** 3열 |

화면은 **가로 3열**이고, **세 분류는 서로 독립**입니다.

```
 대분류(업무성격)   중분류(거래처)      소분류
┌──────────────┐ ┌────────────────┐ ┌────────────┐
│ 정산    할12 │ │ 마리오아울렛 할24│ │ 하프  할8  │
│ 영업    할27 │ │ 대구백화점   할2 │ │ 패플  할3  │
│ CS       할2 │ │ 엔터식스     할5 │ │            │
└──────────────┘ └────────────────┘ └────────────┘
 + 새 대분류      + 중분류 추가       + 소분류 추가
```

- **어느 쪽에도 묶이지 않습니다.** 마리오아울렛에 *정산* 업무도 *영업* 업무도 있을 수 있으니,
  세 칸을 자유롭게 조합해서 쓰면 됩니다.
- 각 줄에 마우스를 올리면 🔍 **이 분류 할 일 보기** · ✏️ **이름변경** · 🗑 **삭제** 가 나타납니다.
- **이름을 바꾸면 그 분류를 쓰는 할 일 전체에 반영**됩니다. 같은 이름이 이미 있으면 합쳐집니다.
- **삭제는 목록에서만** 빼고, 할 일에 적힌 값은 그대로 남습니다.
- 목록에 없는 이름을 할 일 편집창에 직접 타이핑해도 됩니다 — 저장하면 자동으로 목록에 등록됩니다.
- To-do 화면의 세 필터도 독립이라 **겹쳐서** 걸립니다(예: 대분류 정산 + 중분류 마리오아울렛).

### 🔐 Passwords (Password 관리자)
거래처·몰 백오피스 로그인 정보를 암호화해 보관하는 곳입니다. (메뉴: Passwords)

1. 처음 한 번 **마스터 비밀번호**를 만듭니다(8자 이상).
   - ⚠️ **이 비밀번호는 어디에도 저장되지 않습니다. 잊으면 복구할 수 없어요.** (잊었을 땐 잠금 화면의 [전체 초기화]로 비우고 새로 만들 수 있지만, 저장했던 계정은 모두 사라집니다)
2. **+ 계정 추가** → 사이트명·URL·아이디·비밀번호 입력 (🎲 버튼 = 강력한 비밀번호 자동 생성)
3. 목록에서:
   - **[아이디] [비번]** 버튼 → 클립보드 복사
   - **[열기 ↗]** 또는 URL 클릭 → 해당 사이트 새 탭으로 이동
4. 자리를 비우면 **10분 후 자동 잠금**(시간 변경 가능). 수동 잠금은 우상단 🔒.

> 비밀번호는 내 브라우저 안에서만 풀립니다. 서버·관리자·다른 사람은 암호문만 볼 수 있어요.

### 🤖 AI 비서
우하단 🤖 버튼 → 말하듯 입력:

- "내일 뭐 있어?" / "이번 주 일정 보여줘"
- "다음 주 화요일 오후에 마리오 미팅 잡아줘"
- "금요일까지 정산 보고서 할 일 추가해줘"
- "OO 업무 완료 처리해줘" / "주간 리포트 만들어줘"

집계·검색도 됩니다.

- "이번 달 정산 몇 건 남았어?" / "채널별로 몇 건씩 남았어?" → 숫자로 답합니다
- "엔터식스 관련 업무 보여줘" / "긴급인데 아직 안 끝난 것" / "박대리 담당 업무"
- "요즘 얼마나 밀렸어?" → 평균 완료 소요일·기한 준수율·지연 현황
- "이번 달 정리해줘" → 월간 리포트

> 완료 포함 여부를 말하지 않으면 **미완료 기준**으로 답합니다. 완료일·마감일이 빈 업무가 있으면 지표가 실제와 다를 수 있다고 함께 알려줍니다.

### 알림 켜기 (기기마다 한 번)

1. 설정 → **푸시 알림** → **[알림 켜기]** → 브라우저 허용
2. **[테스트 발송]**으로 도착 확인
3. 아이폰은 홈 화면 설치(1장) 후에 가능합니다

## 5. 백업과 복원

- 매일 1회 자동 백업 + 복원 직전 자동 백업, **최근 20개 보관**
- 잘못 지웠거나 이상해졌을 때: 설정 → **백업 & 복구** → 목록에서 시점 선택 → **복원**
- 복원 자체도 자동 백업되므로, 복원을 되돌릴 수도 있습니다
- 파일로 소장하고 싶으면 설정 → 데이터 → **내보내기**

## 6. 문제 해결 (FAQ)

| 증상 | 조치 |
|---|---|
| 화면이 옛날 그대로예요 | **Ctrl+Shift+R** 강력 새로고침 (휴대폰은 앱 완전 종료 후 재실행) |
| 시트에 넣은 업무가 앱에 없어요 | 2026-07-28부터 시트는 앱에 반영되지 않습니다. 앱의 **+ 새 할 일**로 직접 추가하세요 |
| 아침 알림이 안 와요 | 설정 → 푸시 알림에서 이 기기가 켜져 있는지 + **[테스트 발송]** 확인. 카카오만 안 오면 "카카오 알림 실패" 경고 푸시가 왔는지 확인 후 관리자에게 |
| 캘린더에 업무가 안 보여요 | 설정 → 구글 캘린더 연동 → **[지금 동기화]**. 구글 캘린더에서 "SCLM" 캘린더가 표시(체크)돼 있는지 확인 |
| Password 관리자 마스터 비밀번호를 잊었어요 | **복구 불가**합니다. 잠금 화면의 **[전체 초기화]**("초기화" 입력 확인) → Password 관리자를 새로 시작하고 계정을 다시 입력하세요 |
| 앱 로그인 비밀번호를 잊었어요 | 관리자에게 문의 — `wrangler pages secret put APP_PASSWORD`로 재설정 후 재배포하면 됩니다(데이터는 그대로) |
| 실수로 데이터를 지웠어요 | 5장 백업 복원으로 되돌리세요 |
| "다른 곳에서 먼저 저장했어요" 창이 떠요 | 다른 기기·탭에서 먼저 저장했다는 뜻입니다. 대개 **[서버 것 불러오기]**가 안전해요(이 화면의 변경은 버려집니다). 이 화면 내용이 확실히 최신일 때만 [내 것으로 덮어쓰기]를 누르세요 |
| 오프라인인데 저장했어요 | 온라인 복귀 시 "보류된 변경" 확인 창이 뜹니다 — 내용 확인 후 반영/폐기 선택 |

## 7. 나만의 SCLM 만들기 (별도 인스턴스)

자기 데이터로 따로 쓰려면 저장소를 복제해 본인 Cloudflare 계정에 배포합니다. 개발 지식이 조금 필요합니다.

1. 준비물: GitHub · Cloudflare 계정(무료), Node.js, (선택) 구글 클라우드·카카오 개발자 계정
2. `git clone` → `cd web && npm install`
3. Cloudflare에서 D1(`scheduler-db`)·R2(`sclm-files`) 생성 → `wrangler.toml`의 id 교체 → `npm run db:init`
4. 시크릿 등록(`APP_PASSWORD` 등 — [TECH-SPEC.md](TECH-SPEC.md) 6장 목록 참고) → `npm run deploy`
5. 연동 설정은 각 문서를 따라 진행:
   - 구글 캘린더·시트: [web/GOOGLE-SETUP.md](../web/GOOGLE-SETUP.md)
   - 웹푸시·카카오 알림: [web/PUSH-SETUP.md](../web/PUSH-SETUP.md)
   - 매일 알림 크론: `cd web/push-cron && npx wrangler deploy`
